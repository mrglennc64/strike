GETTING STARTED
================================================================================

1. INSTALL DEPENDENCIES (2 minutes)
   cd backend
   pip install -r requirements.txt

2. GET FRED API KEY (1 minute)
   Sign up free: https://fred.stlouisfed.org/docs/api/api_key.html

3. CONFIGURE ENVIRONMENT (1 minute)
   echo "FRED_API_KEY=your_key_here" >> .env

4. TRAIN MODELS (5 minutes)
   curl -X POST http://localhost:8000/api/verticals/economics/train-models

5. START BACKEND (1 minute)
   python -m uvicorn main:app --reload

6. START FRONTEND (1 minute)
   cd frontend && npm run dev

7. OPEN DASHBOARD
   http://localhost:5173/economics

Total: ~15 minutes from zero to working predictor
