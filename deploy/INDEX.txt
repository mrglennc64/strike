INSTALLATION & QUICK START
────────────────────────────────────────────────────────────────────────────────

1. Make scripts executable:
   chmod +x deploy/*.sh

2. Install service files (requires sudo):
   sudo cp deploy/systemd/*.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl start strike-backend.service
   sudo systemctl enable strike-backend.service

3. Install CLV tracking jobs:
   ./deploy/cron-setup.sh install

4. Verify installation:
   ./deploy/cron-setup.sh list
   ./deploy/logs.sh summary

5. Test manually:
   ./deploy/clv-capture.sh open
   ./deploy/logs.sh capture

CONFIGURATION
────────────────────────────────────────────────────────────────────────────────

Environment Variables:

  cron-setup.sh:
    DEPLOY_USER=strike              # User to run jobs as
    USE_SYSTEMD=auto                # Force systemd, cron, or auto-detect
    VENV_PATH=/opt/strike/.venv     # Python virtual environment
    BACKEND_URL=http://localhost:8000

  clv-capture.sh:
    BACKEND_URL=http://localhost:8000  # Backend API URL
    CLV_API_KEY=token                  # Optional Bearer token
    REQUEST_TIMEOUT=30                 # Request timeout (seconds)
    RETRY_COUNT=3                      # Retry attempts
    RETRY_DELAY=5                      # Delay between retries
    DEBUG=1                            # Enable debug logging

  monitoring.sh:
    BACKEND_URL=http://localhost:8000
    ALERT_EMAIL=ops@example.com
    ALERT_SLACK=https://hooks.slack.com/services/...
    MAX_LOG_AGE_MINUTES=30

TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────────────

Backend not starting:
  journalctl -u strike-backend.service -n 50
  cat /etc/strike/backend.env
  lsof -i :8000

CLV jobs not running:
  ./deploy/cron-setup.sh list
  crontab -l
  DEBUG=1 ./deploy/clv-capture.sh open

Health checks failing:
  ./deploy/monitoring.sh
  curl http://localhost:8000/health

High memory usage:
  Edit /etc/systemd/system/strike-backend.service
  Change: MemoryLimit=256M
  sudo systemctl daemon-reload && sudo systemctl restart strike-backend.service

API endpoints unreachable:
  curl -v http://localhost:8000/api/clv/capture
  curl -v http://localhost:8000/api/clv/calculate

Log file issues:
  ./deploy/logs.sh summary
  ./deploy/logs.sh errors
  du -sh logs/
  ./deploy/logs.sh rotate
