✓ COMPLETE FASTAPI BACKEND with 10 Required Features:

  1. ✓ /api/auth (login/signup)
     - POST /signup: Create account with bcrypt password hashing
     - POST /login: Authenticate and return JWT token
     - GET /me: Get current user

  2. ✓ /api/bankroll (set initial, query current)
     - POST /initialize: Set initial capital
     - GET /current: Query balance, ROI, P&L
     - PUT /update: Update balance after settlement

  3. ✓ /api/predictions (submit prediction: event, prob, market_prob)
     - POST /: Submit event prediction with probabilities
     - GET /{id}: Get specific prediction
     - GET /: List predictions with filtering
     - Auto-calculates edge percentage

  4. ✓ /api/kelly (calculate kelly_fraction)
     - POST /calculate: Full Kelly criterion calculation
     - POST /suggest-stake: Personalized stake based on bankroll
     - Formula: f* = (bp - q) / b
     - Validates and clamps results

  5. ✓ /api/place-bet (submit bet with state machine)
     - POST /: Place new bet in PENDING state
     - POST /{id}/transition: Move through state machine
     - GET /{id}: Get bet details
     - Risk limits enforced via middleware

  6. ✓ /api/positions (list active bets)
     - GET /active: Active (LIVE) bets only
     - GET /all: All bets with status filtering
     - GET /summary: Comprehensive position summary with P&L

  7. ✓ /api/settle (mark bet as settled with actual outcome)
     - POST /{id}: Settle bet with outcome and return
     - POST /{id}/void: Void bet and return stake
     - Automatic bankroll update
     - P&L calculation

  8. ✓ /api/audit-log (query audit trail)
     - GET /: List logs with filtering
     - GET /action/{action}: Filter by action type
     - GET /entity/{type}/{id}: Logs for specific entity
     - GET /summary: Activity summary

  9. ✓ Risk Limits Middleware
     - Enforces before bet execution
     - MAX_SINGLE_BET_FRACTION: 5% of bankroll
     - MAX_DAILY_LOSS_FRACTION: 10% daily loss limit
     - Checks: bankroll sufficient, single bet limit, daily loss limit
     - Returns 429 if limits exceeded

  10. ✓ State Machine for Bets
      - PENDING → SUBMITTED → CONFIRMED → LIVE → SETTLED
      - Also: PENDING → CANCELLED, LIVE → VOID
      - Timestamp tracking for each state
      - Terminal states: SETTLED, CANCELLED, VOID
      - Service: BetStateMachine class with validation
